# Installation
The OpenCASA Fiji plugin requires the JavaML library to run. Place the file javaml-0.1.7.jar in your Fiji plugins/jars folder before starting Fiji.

# Test data
Example datasets are available for testing the modules here: https://doi.org/10.6084/m9.figshare.12597920.v1
This step is optional but recommended if you want to try the plugin with sample data and validate the workflow.
